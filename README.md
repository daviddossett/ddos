## 🎯 What's This?

Welcome to the source code of my digital home on the internet! Built with modern web tech and a sprinkle of personality.

## 🛠️ Tech Stack

- **Next.js** - Because React is cool, but Next.js is _cooler_
- **TypeScript** - Keeping those bugs at bay
- **Tailwind CSS** - Making things pretty without the CSS headaches
- **React Markdown** - Words, but fancier

## 🏃‍♂️ Getting Started

```bash
# Install the goods
npm install

# Fire up the dev server
npm run dev

# Build for production (when you're feeling fancy)
npm run build

# Lint your code (be a good citizen)
npm run lint
```
