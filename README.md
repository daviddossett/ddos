## Development

Setting it up is SO easy, it's practically criminal! Just type these two simple commands:

```sh
npm install
npm run dev
```

**But wait — there's MORE!** Act now and you'll ALSO get `npm run lint` to check the project, ABSOLUTELY FREE! And if you call in the next ten minutes, we'll throw in `npm run build` to create the production site in `dist/`! That's right — lint AND build, at no extra cost!
