# This is my website (and it has Opinions™)

Welcome to the code that turns caffeine into pixels and ships a personal site to the internet.

## What’s in here?

- **A Next.js site**: React, routing, the usual magic.
- **Tailwind CSS**: because writing CSS by hand is a personal choice I rarely make.
- **Static assets**: shiny things in `public/`.

## Run it locally (summon the site)

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Then open `http://localhost:3000` and admire your excellent decision-making.

## Useful spells (aka scripts)

- **Dev**: `npm run dev`
- **Build**: `npm run build`
- **Start (prod)**: `npm run start`
- **Lint**: `npm run lint`

## Where things live

- **Pages**: `pages/`
- **Components**: `components/`
- **Styles**: `public/globals.css` (plus Tailwind config)
- **Images**: `public/images/`

## Deployment vibes

This repo is set up to be deployed like a typical Next.js site. If something breaks, it’s probably:

1. Node version differences
2. A missing env var
3. The internet doing internet things
