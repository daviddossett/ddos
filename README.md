Hi there! 👋 This is the home of my personal website, a little corner of the
internet where I share what I'm working on and thinking about. It's built with
Astro and deployed as a static site, so it stays simple and fast. Thanks for
stopping by!

## Development

```sh
npm install
npm run dev
```

Run `npm run lint` to check the project and `npm run build` to create the
production site in `dist/`.
