*Here, in its natural habitat, we find David Dossett's personal website — a
rare specimen, built with Astro and deployed, quietly, as a static site.*

## Development

To approach the creature without startling it, we first gather its
dependencies… then, ever so gently, coax it awake:

```sh
npm install
npm run dev
```

Observe. Run `npm run lint` to check the project's health from a respectful
distance, and `npm run build` to watch it complete its remarkable migration
into the production site in `dist/`. Truly, nature is extraordinary.
