# 👋 Welcome!

Hi there, and thanks for stopping by! This is the code behind
[David Dossett's personal website](https://ddossett.com), built with
[Astro](https://astro.build) and deployed as a static site.

Feel free to poke around, borrow ideas, or just see how it all fits together.

## Getting started

Getting it running on your machine only takes a minute:

```sh
npm install
npm run dev
```

Once the dev server is up, open the local address it prints and you'll see the
site, with changes showing up as you edit.

## Handy commands

| Command           | What it does                                      |
| ----------------- | ------------------------------------------------- |
| `npm run dev`     | Starts the dev server                             |
| `npm run lint`    | Checks the project (runs `astro check`)           |
| `npm run build`   | Builds the production site into `dist/`           |
| `npm run preview` | Previews the production build locally             |

## Finding your way around

- `src/pages/`: the site's pages
- `src/components/`: the building blocks (header, footer, experience, projects)
- `src/layouts/`: the shared page layout
- `src/styles/`: global styles
- `public/`: static assets like fonts, images, and favicons

## Deployment

Whenever changes land on `main`, a GitHub Actions workflow checks the project,
builds it, and publishes it to GitHub Pages. No manual steps needed. 🎉

Happy exploring!
