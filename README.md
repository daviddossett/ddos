# ddossett.com

David Dossett's text-first personal portfolio, built with [Astro](https://astro.build/)
and deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run lint` | Run Astro and TypeScript checks |
| `npm run build` | Build the production site in `dist/` |
| `npm run preview` | Preview the production build locally |

Pushes to `main` are checked, built, and deployed through GitHub Actions.
