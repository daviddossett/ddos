# David Dossett

My personal site at [ddossett.com](https://ddossett.com).

I'm a product designer based in Seattle, working on the Copilot Labs team at GitHub. Previously, I led design for VS Code. I love building tools for developers.

The site is a small home for my background, selected projects, and links to find me elsewhere. Built with [Astro](https://astro.build), styled with plain CSS, and published to GitHub Pages.

## Run locally

Use Node.js 24 to match the deployment workflow.

```sh
npm install
npm run dev
```

`npm run lint` checks the project with Astro. `npm run build` generates the static site in `dist/`, and `npm run preview` serves that build locally.
